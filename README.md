# App del Clima "Climita

Pequeña aplicación web desarrollada para la materia de Desarrollo de Software Multiplataforma, la cual consume la API pública de **Open-Meteo** para mostrar el pronóstico del tiempo en tiempo real[cite: 1, 2].

## Declaración de Uso de Inteligencia Artificial

Tal como se solicita en los lineamientos del trabajo, a continuación se detallan las herramientas de IA utilizadas y su propósito en el proyecto:

Herramientas utilizadas:ChatGPT / Claude

* Uso de cada herramienta:
   **Generación de código:** 
   Se utilizó para estructurar la base inicial de JavaScript encargada de realizar la petición fetch a la API de Open-Meteo y manejar la respuesta asíncrona.
   **Depuración y Errores:** 
   Se consultó para solucionar un problema de CORS al momento de conectar el script con el servidor local y para validar el manejo de errores (respuestas vacías, sin conexión)

* **¿Qué parte del proyecto hice sin ayuda de IA?** 
  * La activación del Github Student Developer Pack
  * El acomodo del trabajo y testeo del proyecto
  * La estructura general de carpetas y los commits realizados de forma progresiva en el repositorio de GitHub.
